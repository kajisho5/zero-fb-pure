### 0.3 原理的な限界（正直に書いておく）

- **純粋なサイン波に近い音は、音源であっても切る。** シンセの単音、口笛、チューニング用の信号音などは、ハウリングと見分けがつかない。これは AI を使わない方式の限界で、STRENGTH を下げるか BYPASS で避ける。
- **200 Hz 以下は広めに切れる。** 解析の周波数分解能が約 23 Hz のため、低域では隣の 1〜2 バンドも一緒に下がる（§5.7）。
- **閉ループ性能（GBF +6 dB、ハンチング 0 回、50 ms 収束）は未検証。** この設計書の定数は【設計値】で、Phase 2 Step 2 のベンチで初めて合否が出る。特に 50 ms 収束が最も厳しい。

## 4. Signal Path（遅延 0 サンプル・サンプル単位）

処理は必ず「サンプルのループを一番外側」にする。ブロック長によって計算の順序や分岐が変わる書き方は禁止（§8.2 ZL-5 のため）。

### 4.1 経路の切り替えとビット完全一致

出力は次の式で作る。$w[n]$ は「処理側の混ぜ具合」（0〜1）。

$$y[n] = \begin{cases} x[n] & w[n] = 0 \\ (1 - w[n])\,x[n] + w[n]\,p[n] & 0 < w[n] < 1 \\ p[n] & w[n] = 1 \end{cases}$$

- $p[n]$ は処理側（§4.2〜§4.7）の出力。
- $w$ の目標値は、`bypass == ON` または `strength == 0` のとき 0、それ以外は 1。
- $w$ は目標へ向けて 5 ms（$\mathrm{round}(0.005 f_s)$ サンプル）の直線で動く。
- **$w = 0$ の定常状態では、$x[n]$ をそのまま代入する（掛け算・足し算を通さない）。** これでビット完全一致（誤差 0.0）を保証する。
- $w = 0$ の間も、処理側のフィルタ・解析・スコア・FSM はすべて動かし続ける（復帰した瞬間から会場の状態に合った抑制がかかるように）。
- Mono→Stereo のバイパスは、入力を L と R の両方へそのまま代入する。

MUTE との関係：`bypass == ON` なら MUTE は無視して素通し。`bypass == OFF` かつ `mute == ON` なら、`strength == 0` でも無音にする（このときはビット完全一致の対象外）。

### 4.2 DC Blocker（20 Hz・1 次ハイパス）

$$g_{dc} = \tan(\pi \cdot 20 / f_s),\quad G_{dc} = \frac{g_{dc}}{1 + g_{dc}}$$

```
v  = (x - s) * G_dc
lp = v + s
s  = lp + v
out = x - lp
```

状態 $s$ はチャンネルごとに 1 個。初期値 0。

### 4.3 EQ バンクのバンド配置【検算済】

中心周波数は ERB 尺度で等間隔に 40 本、60 Hz〜15 kHz。

$$E(f) = 21.4 \log_{10}(1 + 0.00437 f),\qquad E^{-1}(e) = \frac{10^{e/21.4} - 1}{0.00437}$$

$$e_b = E(60) + b \cdot \frac{E(15000) - E(60)}{39},\qquad f_b = E^{-1}(e_b),\quad b = 0 \dots 39$$

両端の外側に仮想の隣（$f_{-1} = E^{-1}(e_0 - \Delta e)$、$f_{40} = E^{-1}(e_{39} + \Delta e)$、$\Delta e$ は間隔）を置く。

各バンドの $Q_b$ は、「隣との中間点でちょうど半分の dB になる」幅を基準に、高域の周波数ゆがみ（双一次変換の歪み）を先に見込んで決める。

$$g_b = \tan(\pi f_b / f_s)$$

$$c_b^{\pm} = \left| \omega - \frac{1}{\omega} \right|,\quad \omega = \frac{\tan(\pi f_{mid}^{\pm} / f_s)}{g_b},\quad f_{mid}^{\pm} = \min\!\left(\frac{f_b + f_{b \pm 1}}{2},\ 0.49 f_s\right)$$

$$Q_b = \frac{1}{\kappa \cdot \max(c_b^{+}, c_b^{-})},\qquad \kappa = 1.2$$

全バンドがベル型（ピーキング）。両端は中心が 60 Hz と 15 kHz に乗っており、$Q$ が低い（1.55 と 2.9〜6.6）ので、60 Hz〜15 kHz を隙間なく覆う。

### 4.4 SVF（Cytomic / Andrew Simper の線形台形積分型）

出典: Andrew Simper, "Solving the continuous SVF equations using trapezoidal integration and equivalent currents"（Cytomic 技術資料 `SvfLinearTrapOptimised2.pdf`）。Direct Form I/II は使わない。

バンド $b$ のゲイン $G_b$ [dB]（$\le 0$）から係数を作る：

$$A_b = 10^{G_b / 40},\quad k_b = \frac{1}{Q_b A_b},\quad a_{1,b} = \frac{1}{1 + g_b (g_b + k_b)},\quad a_{2,b} = g_b\, a_{1,b},\quad a_{3,b} = g_b\, a_{2,b},\quad m_{1,b} = k_b (A_b^2 - 1)$$

1 サンプルの計算（入力 `v0`、状態 `ic1eq`・`ic2eq`）：

```
v3    = v0 - ic2eq
v1    = a1 * ic1eq + a2 * v3
v2    = ic2eq + a2 * ic1eq + a3 * v3
ic1eq = 2 * v1 - ic1eq
ic2eq = 2 * v2 - ic2eq
out   = v0 + m1 * v1
```

- バンド 0 の出力をバンド 1 の入力へ、と順に 40 段つなぐ。
- $G_b = 0$ のとき $m_1 = 0$ になり、`out = v0`（そのバンドは素通し）。
- **全バンドを毎サンプル必ず計算する。**「0 dB だから飛ばす」はしない（再開時のクリックを避ける）。
- 状態はチャンネルごと・バンドごとに 2 個。L/R は同じ係数を使い、2 チャンネルを 1 つの SIMD レジスタに載せて同時に計算してよい。

### 4.5 係数の毎サンプル増分更新

制御フレームごとに新しい目標係数 $(a_1, a_2, a_3, m_1)^{new}_b$ が決まる。次の $H$ サンプルの間、各係数を直線で動かす。

$$\delta = \frac{c^{new} - c^{cur}}{H},\qquad c^{cur} \leftarrow c^{cur} + \delta \quad（毎サンプル）$$

- $H$ サンプル後に $c^{cur} = c^{new}$ を代入して誤差の蓄積を消す。
- 4 係数 × 40 バンド = 160 個の加算を SIMD（NEON / AVX2）で一括に行う。
- $g_b$ は固定なので、直線補間の途中でも $a_2 = g a_1$、$a_3 = g^2 a_1$ の関係が保たれ、途中の係数は必ず「ある正の $k$ に対応する正しい係数」になる。したがって補間中に不安定にならない。

### 4.6 異常ガード

EQ の出力 $v[n]$ と入力 $x[n]$ の両方を見る。しきい値 $\Theta_g = 10^{24/20} = 15.849$。

```
fault(n) = !(|x[n]| <= Θg) || !(|v[n]| <= Θg)      // NaN・Inf・+24 dBFS 超をすべて拾う
```

状態は `NORMAL` / `MUTED` / `RECOVER` の 3 つ。

```
NORMAL:
    if fault: 
        出力を即 0（このサンプルから）
        DC Blocker・全 SVF の状態を 0 にする
        解析リングバッファを 0 で埋め、全ビンのスコアと連続数を 0 にする
        clean = 0;  state = MUTED
MUTED:
    出力 0。処理側フィルタへの入力も 0 を入れる
    if !(|x[n]| <= Θg): clean = 0  else clean += 1
    if clean >= 64:
        全バンドの目標を FLOOR にして干渉補正を解き（0 から 12 反復）、係数を即セット
        （ランプなし。無音中なのでクリックにならない）
        guardRel = 1;  fade = 0;  state = RECOVER
RECOVER:
    fade を 5 ms かけて 0→1（直線）。出力 = fade * 通常の処理結果
    途中で fault が出たら NORMAL の fault と同じ処理へ
    fade == 1 で state = NORMAL
```

「Floor 側からの復帰」＝ 最も深く切った状態から音を戻し、そこから 1.0 秒で通常の深さへ上げる、という意味で定義した。

復帰後の深さは `guardRel`（1→0、制御フレームごとに $T_f / 1.0\,\mathrm{s}$ ずつ減る）で決める。制御フレームでは各バンドの目標を $t_b \leftarrow \min(t_b,\ F_{dB} \cdot \mathrm{guardRel})$ としてから FLOOR で止める。ガード作動時、検出側（スコアと FSM）は初期状態に戻す。

クロスフェードの途中（$0 < w < 1$）に入力が異常値だった場合、混ぜる原音側は 0 として扱う（異常値を出力へ通さない）。$w = 0$ の定常（バイパス）では入力をそのまま出す。

### 4.7 瞬時ソフトリミッター（遅延 0）

天井 $C = 10^{-0.5/20} = 0.94406$、折れ点 $T = 0.5$（−6.02 dBFS）。

$$L(v) = \begin{cases} v & |v| \le T \\ \mathrm{sgn}(v)\left[T + (C - T)\tanh\!\left(\dfrac{|v| - T}{C - T}\right)\right] & |v| > T \end{cases}$$

- 折れ点で値と傾きが連続。どんな入力でも $|L(v)| < C$。
- $|v| \le T$ は代入のみ（計算を通さない）。

### 4.8 MUTE

出力ゲイン $m$ を 5 ms の直線で 1↔0 に動かし、最後に掛ける。$m = 1$ の定常では掛け算を省く。

### 4.9 デノーマル対策

`processBlock` の先頭で `juce::ScopedNoDenormals` を置く。

## 5. Control Path（解析と制御）

> この章は文書バージョン 0.7.0 で、現在の実装に合わせて書き直した。Phase 1 の設計からの変更の経緯は §13.3 と §14 にある。

### 5.1 実行のしかた

- サンプルごとに解析用リングバッファへ 1 個書く。書いた数が $H$ の倍数になった**そのサンプルの処理直後**に、制御フレームを 1 回実行する（§5.3〜§5.10）。
- 結果（新しい目標係数）は**次のサンプルから** $H$ サンプルかけて反映する。信号経路が解析を待つことはない。
- 制御フレームはオーディオスレッド内で動く。ヒープ確保・ロック・システムコールは禁止。必要なバッファはすべて `prepareToPlay` で確保する。
- 最初の $N$ サンプルが溜まるまでは、足りない部分を 0 として解析する。

### 5.2 解析用の前処理

チャンネルごとに、40 Hz・1 次のハイパスを通す（DC と超低域を落とす）。

$$\ell[n] = \ell[n-1] + \alpha\,(x[n] - \ell[n-1]),\quad \alpha = 1 - e^{-2\pi \cdot 40 / f_s},\qquad r[n] = x[n] - \ell[n]$$

$r[n]$ を長さ $N$ のリングバッファへ入れる。異常ガードが作動している間は入れない。

### 5.3 スペクトル変換

- 窓: 周期型 Hann。$w[i] = 0.5 - 0.5\cos(2\pi i / N)$
- 直近 $N$ サンプルに窓を掛け、長さ $N$ の複素 FFT を 1 回行う。Stereo は L を実部、R を虚部に入れ、結果 $Z_k$ から $X_{L,k} = (Z_k + \overline{Z_{N-k}})/2$、$X_{R,k} = (Z_k - \overline{Z_{N-k}})/(2i)$ で左右を取り出す（FFT を 1 回で済ませるため）。
- パワーを「サイン波の振幅がそのまま出る」ように正規化する: $p_k = \left(\dfrac{2}{\sum_i w[i]}\right)^2 |X_k|^2$
- 解析するビンの範囲: $k_{lo} = \max(3, \lceil 50 / (f_s/N) \rceil)$ から $k_{hi} = \min(N/2 - 6, \lfloor 16000 / (f_s/N) \rfloor)$。

### 5.4 ステレオの合成

Stereo のときは、ビンごとに左右のパワーの大きい方を使う（Mono はそのまま）。

$$p_k = \max(p_{L,k},\ p_{R,k}),\qquad L_k = 10\log_{10}(p_k + 10^{-18})\ \text{[dBFS]}$$

位相を使わないので、L/R が逆相でも打ち消し合わない。発振がどちらか片方にしか無くても、そのままの大きさで見える。

### 5.5 山の判定（レベルに依存しない）

**山**: $L_k \ge -72$ dBFS かつ $p_k \ge p_{k\pm1}$ のビン。

**突出度**: 周りの平均との差。平均は、自分の周り ±4 ビンを除いた単純平均（パワー）。

$$W_k = \mathrm{clamp}(\mathrm{round}(0.26\,k),\ 16,\ 48),\qquad \mu_k = \operatorname{mean}\{\,p_j : 5 \le |j - k| \le W_k\,\},\qquad P_k = L_k - 10\log_{10}\mu_k$$

（急に伸びる発振はスペクトルの裾が広がるので、±4 ビンまで除く。累積和で計算する。）

**倍音の候補**: 山のうち、±2 ビン離れた所より 3 dB 以上高いもの（$L_k - \max(L_{k-2}, L_{k+2}) \ge 3$）。

**発振の候補**: 倍音の候補のうち $P_k \ge 12$ dB のもの。ただし次の「倍音列の判定」に当たるものは除く。

**倍音列の判定**（声や楽器を発振と間違えないため）: 候補 $k$ が、次のどちらかの形で「等間隔に並ぶ 3 本」の一員なら、倍音とみなして見送る。相手 $a$、$b$ は倍音の候補で、レベルが候補の 15 dB 下まで、間隔 $d = |a - k|$ は 70〜1200 Hz。位置のずれは $2 + d/64$ ビンまで許す。

- $k$ が真ん中: $b \approx 2k - a$
- $k$ が端: $b \approx 2a - k$

**見送らない例外**（倍音列に当たっても発振として扱う）:

1. **伸び続けている山**。8 フレーム（約 43 ms）の区間を 2 つ続けて見て、どちらも 3〜30 dB 上がっており、新しい区間の伸びが古い区間の 0.6 倍以上で、途中に今より 0.5 dB 以上高い時が無いこと。声の立ち上がり（一気に上がって止まる）は外れ、発振（同じ調子で上がり続ける）は当たる。遅延が主体のループでは発振の候補そのものが等間隔に並ぶため、この例外が要る。
2. **緊急**。$L_k \ge -12$ dBFS かつ $P_k \ge 20$ dB。

**周波数**: 候補の周波数は、両隣のレベルからの放物線補間で求める（誤差は 1 Hz 未満。§15.4）。

$$\delta = \mathrm{clamp}\!\left(\frac{0.5\,(L_{k-1} - L_{k+1})}{L_{k-1} - 2L_k + L_{k+1}},\ -0.5,\ 0.5\right),\qquad f = (k + \delta)\,\frac{f_s}{N}$$

### 5.6 確認とスコア

発振の候補を ±2 ビンへ広げ、ビンごとに「続いているか」を見る。各ビンは、近く（±2 ビン）のいちばん強い候補の周波数 $f$ と、5 ビンの最大レベル $L^5$ を使う。

```
if 近くに候補がある:
    n = streak + 1                         // この山を続けて見たフレーム数
    if n == 1: runMax = L5;  rawMin = rawMax = fAvg = f
    else:
        fAvg += (f - fAvg) * (n <= 4 ? 1/n : 0.25)     // ならした周波数
        rawMin = min(rawMin, f);  rawMax = max(rawMax, f)
        n == 3 なら avgMin = avgMax = fAvg、n > 3 なら avgMin・avgMax を fAvg で更新
        if rawMax - rawMin > 16 Hz  or  (n >= 3 and avgMax - avgMin > 4 Hz):
            streak = 0;  score = 0;  n = 1 として上の初期化をやり直す   // 周波数が動いた = 声や楽器
    runMax = max(runMax, L5)
    if runMax - L5 > 3 dB:                 // 山から落ち込んだ = 揺れている
        streak = 0;  confirmed = false
    else:
        streak += 1;  confirmed = true
        rising = (L5 >= 前フレームの L5 - 0.6 dB)   // まだ収まり始めていない
else:
    streak = 0;  confirmed = false

score = clamp(score + (confirmed ? +Δup : -Δdn), 0, 1)
howlNow = confirmed and rising             // 深くしてよいフレームかどうか
```

| 定数 | 値【設計値】 | 意味 |
|---|---|---|
| $\Delta_{up}$（通常） | $T_f / 80\,\mathrm{ms}$ | 0→1 に 80 ms |
| $\Delta_{up}$（警戒中） | $T_f / 16\,\mathrm{ms}$ | 0→1 に 16 ms |
| $\Delta_{dn}$ | $T_f / 400\,\mathrm{ms}$ | 1→0 に 400 ms |
| 警戒モード | 1.5 秒 | ノッチか帯域が抑制を始めた（再開した）瞬間から。スコアの上がり方だけを速める |

**周波数の安定を 2 通りで見る理由**: 遅延が長いループでは、発振の候補どうしの間隔（約 32〜40 Hz）が解析の分解能（山の幅 約 94 Hz）より狭くなる。2 本が同時に伸びると 1 つの山に見え、うなりで見かけの周波数が ±6 Hz ほど小刻みに揺れる。その場の値だけで「4 Hz 以上動いたら声」と決めると、この発振を 1 秒以上見逃した（§15.5）。そこで、その場の揺れは 16 Hz まで許し、ならした値（中心）が 4 Hz を超えて動くものを声や楽器とみなす。

**平滑化**: $\bar{s}_k = (s_{k-2} + 2 s_{k-1} + 3 s_k + 2 s_{k+1} + s_{k+2}) / 9$

### 5.7 ノッチへの割り当て

ノッチは 12 本（§4.4 と同じ SVF のベル、$Q = 30$、カット専用、帯域 EQ の後ろに直列）。各ノッチは周波数・深さ $e$（0〜1）・状態を持つ。

制御フレームごとに：

1. 使っているノッチの周波数の ±3 ビンを「ノッチの受け持ち」とする。
2. すべての発振の候補（山）について：
   - 周波数が近いノッチ（差が $\max(6\,\mathrm{Hz},\ 1.75\%)$ 以内）があれば、そのノッチのもの。$\bar{s}_k \ge 0.25$ かつ `howlNow` なら、そのノッチを「このフレームで深くする」。
   - 近いノッチが無く、$\bar{s}_k \ge 0.50$ かつ `howlNow` で、空きノッチがあれば、いちばん長く空いているノッチをその周波数に割り当てる。警戒モードを始める。
   - それ以外（スコアが足りない、または空きが無い）は、その山の ±2 ビンを受け持ちから外し、帯域側（§5.8）に任せる。
3. ノッチごとに状態を進める（定数は §5.8 と共通）：

```
ENGAGED: 深くするフレームなら e = min(1, e + Tf/80ms)、静かな時間 = 0
         そうでなければ静かな時間 += Tf。0.3 秒に達したら
             holdLeft = min(15 秒 * 2^strikes, 120 秒) * (1 + 0.5 * ノッチ番号 / 12);  e = e * 0.6;  → HOLD
HOLD:    holdLeft -= Tf
         深くするフレームなら → ENGAGED（e を進める。警戒モードを始める）
         holdLeft <= 0 なら → RELEASE
RELEASE: 深くするフレームなら strikes = min(strikes + 1, 3) → ENGAGED
         そうでなければ e -= Tf/8秒。0 になったらノッチを空ける
```

保持の長さをノッチの番号（0〜11）で最大 1.5 倍までずらすのは、同じ頃に掴んだノッチをいっせいに戻し始めないため（§15.5）。

ノッチの周波数を付け替えるのは、そのノッチが 0 dB のときだけ（係数を即セットし、状態を 0 にする）。

「$e = e \times 0.6$」は、深くなりすぎた分を返すためのもの。発振が収まり始めてから検出が止まるまでの遅れのぶん、必要以上に深くなる（§15.3）。

### 5.8 帯域（40 バンド）側

ノッチの受け持ちでないビンだけを使う。バンド $b$ の担当ビン $K_b$ は、$f_k$ が $[\,(f_{b-1} + f_b)/2,\ (f_b + f_{b+1})/2\,)$ に入るビン（$b = 0$ の下端は 50 Hz、$b = 39$ の上端は 16 kHz。空なら $f_b$ に最も近いビン）。

$$S_b = \max_{k \in K_b,\ \text{受け持ち外}} \bar{s}_k,\qquad \mathrm{howl}_b = \bigvee_{k \in K_b,\ \text{受け持ち外}} \mathrm{howlNow}_k$$

| 定数 | 値【設計値】 | 意味 |
|---|---|---|
| $\theta_{on}$ | 0.50 | 抑制を始めるスコア |
| $\theta_{off}$ | 0.25 | 「収まった」とみなすスコア。保持・解放中に再開するスコア |
| 深くする速さ | 0→1 に 80 ms | `howl` のフレームだけ進む |
| 戻す割合 | 0.6 | 保持に移るときに掛ける |
| 基本の Hold | 15 秒 | 再発のたびに倍（最大 3 回、上限 120 秒） |
| Release | 1→0 に 8 秒 | |
| 再発とみなす時間 | 10 秒 | IDLE に戻ってからこの時間内の再開 |
| 忘れる時間 | 60 秒 | IDLE がこれだけ続いたら `strikes` を 0 に |

```
IDLE:    e = 0;  idleFor += Tf;  idleFor >= 60 秒なら strikes = 0
         S >= θon なら:
             以前に抑制したことがあり idleFor <= 10 秒なら strikes = min(strikes + 1, 3)
             → ENGAGED（警戒モードを始める。howl なら e を進める）
ENGAGED: howl なら e = min(1, e + Tf/80ms)
         S < θoff なら holdLeft = min(15 秒 * 2^strikes, 120 秒);  e = e * 0.6;  → HOLD
HOLD:    holdLeft -= Tf
         S >= θoff かつ howl なら → ENGAGED
         holdLeft <= 0 なら → RELEASE
RELEASE: S >= θoff かつ howl なら strikes = min(strikes + 1, 3) → ENGAGED
         そうでなければ e -= Tf/8秒。0 になったら idleFor = 0 → IDLE
```

`RESET` と異常ガードの作動で、全バンド・全ノッチ・全スコアを初期状態に戻す。

低域では 1 バンドの幅（約 31 Hz）がビン幅（約 23 Hz）に近いため、平滑化の裾が隣の 1〜2 バンドにかかる（§0.3 の限界）。

### 5.9 STRENGTH と FLOOR

$S$ を STRENGTH（0〜1）とする。

$$D_{max} = 36\ \mathrm{dB} \times S^{1.6}$$

帯域の目標（バンド中心での応答）とノッチのゲイン [dB]：

$$t_b = \max(-e_b\, D_{max},\ F_{dB}),\qquad G^{notch}_n = \max(-e_n\, D_{max},\ F_{dB})$$

| STRENGTH | 25% | 50% | 75% | 90% | 100% |
|---|---|---|---|---|---|
| $D_{max}$ [dB] | 3.9 | 11.9 | 22.7 | 30.4 | 36.0 |

$S = 0$ で $D_{max} = 0$（何もしない。このとき §4.1 により素通し）。

### 5.10 帯域干渉の補正（非正制約つき Projected Gauss-Seidel・3 反復）

直列のベルは裾が重なるので、目標 $t_b$ をそのまま各バンドに入れると切りすぎる。「バンド中心での合計応答が $t_b$ になる」ゲイン $g_b \le 0$ を解く。

**影響率行列**（`prepareToPlay` で $f_s$ ごとに計算）。バンド $j$ を $G$ dB にしたときの、$f_b$ での応答 [dB]：

$$R_{bj}(G) = 10\log_{10}\frac{(1 - \omega^2)^2 + (A\,\omega / Q_j)^2}{(1 - \omega^2)^2 + (\omega / (Q_j A))^2},\qquad \omega = \frac{\tan(\pi f_b / f_s)}{\tan(\pi f_j / f_s)},\quad A = 10^{G/40}$$

2 点（$G_a = -6$、$G_c = -24$）から、深さによる変化を直線で近似する：

$$\rho^{a}_{bj} = \frac{R_{bj}(G_a)}{G_a},\quad \rho^{c}_{bj} = \frac{R_{bj}(G_c)}{G_c},\quad \beta_{bj} = \frac{\rho^{c}_{bj} - \rho^{a}_{bj}}{|G_c| - |G_a|},\quad \alpha_{bj} = \rho^{a}_{bj} - \beta_{bj}|G_a|$$

対角は $\alpha_{bb} = 1$、$\beta_{bb} = 0$。バンド $j$ が $g_j$ のとき、$f_b$ への寄与は $g_j(\alpha_{bj} + \beta_{bj}|g_j|)$ と近似する。

**解法**（制御フレームごと。$g$ は前フレームの解から始める）：

```
repeat 3 times:
    for b = 0 .. 39:
        leak = Σ_{j≠b} g[j] * (α[b][j] + β[b][j] * |g[j]|)
        g[b] = min(0, t[b] - leak)
```

性質：
- $g_b \le 0$（持ち上げなし）。漏れ込み `leak` は 0 以下なので $g_b \ge t_b \ge F_{dB}$。
- 隣からの漏れ込みだけで目標より深くなる場所は、$g_b = 0$ にしてもそれ以上戻せない（カット専用のため。持ち上げで補うことはしない）。

精度【検算済】（44.1 / 48 / 96 kHz、バンド中心での誤差の最大値）：

| 設定 | 1 フレーム目（0 から開始） | 2 フレーム目以降 |
|---|---|---|
| 全バンド一様 −6 dB | 0.46 dB | 0.21 dB |
| 全バンド一様 −12 dB | 0.62 dB | 0.09 dB |
| 全バンド一様 −24 dB | 1.05 dB | 0.93 dB |
| 全バンド一様 −36 dB | 2.42 dB | 1.65 dB |
| 単一バンド −12 dB | 0.00 dB | 0.00 dB |
| ランダムに 1〜7 バンドを −3〜−24 dB | — | 最大 0.51 dB（検算 300 通りで 0.44、C++ のテスト 200 通り × 3 レートで 0.51） |

一様 −12 dB のとき、バンドの間（中心以外）の応答は −10.8〜−12.1 dB【検算済】。

### 5.11 ゲインから係数へ

解いた $g_b$ を §4.4 の $G_b$ として係数を計算し、§4.5 の直線ランプの新しい目標にする。

### 5.12 制御フレームの手順（まとめ）

```
1. 異常ガードが MUTED なら何もせず終了
2. 窓掛け → FFT → パワー → ステレオ合成 → L_k                    §5.3, §5.4
3. 山・突出度・倍音列の判定・伸びの判定 → 発振の候補と周波数      §5.5
4. 確認（周波数の安定・落ち込み）→ スコア → 平滑化                §5.6
5. ノッチへの割り当てと、ノッチの状態の更新                       §5.7
6. 帯域のスコアと、帯域の状態の更新                               §5.8
7. D_max → 帯域の目標 t_b とノッチのゲイン → FLOOR               §5.9
8. 帯域は PGS 3 反復 → g_b（ノッチは干渉補正に含めない）          §5.10
9. 帯域とノッチの係数の新目標をセット（H サンプルで直線ランプ）    §5.11
10. 画面用の値を書き出す                                          §6.4
```

## 6. パラメータ・状態保存・画面との受け渡し

### 6.1 パラメータ

| ID | 表示名 | 型 | 範囲 | 既定値 | 刻み | 備考 |
|---|---|---|---|---|---|---|
| `strength` | STRENGTH | float | 0.0〜100.0 % | 75.0 | 0.1 | 0% で素通し（§4.1） |
| `floor` | FLOOR | float | −36.0〜−6.0 dB | −24.0 | 0.1 | 最大カットの上限 |
| `reset` | RESET | bool | OFF / ON | OFF | — | ON になった瞬間に 1 回だけ実行 |
| `mute` | MUTE | bool | OFF / ON | OFF | — | 5 ms ランプ |
| `bypass` | BYPASS | bool | OFF / ON | OFF | — | 5 ms クロスフェード。`getBypassParameter()` でこれを返し、ホスト標準 Bypass と同期 |

- `strength`・`floor` は制御フレームごとに読む（その後のゲイン変化は §4.5 のランプで滑らかになる）。
- `reset` は OFF→ON の変化を検出して実行し、画面のボタンは押した直後に OFF へ戻す。実行内容: 全 FSM を初期化（§5.8）、全スコア・連続数を 0、全フィルタ状態を 0、ゲインを 0 dB へ（1 フレームのランプ）。
- `reset` は保存しない（読み込み時は常に OFF）。

### 6.2 状態の保存

- `AudioProcessorValueTreeState` の内容に `stateVersion = 1` を付けて保存する。
- 検出の途中経過（スコア、FSM）は保存しない。

### 6.3 `prepareToPlay` / `reset`

- `prepareToPlay`: サンプルレートから §2.1 の設定を決め、バンド表・影響率行列・$\ln x_i$ の表・窓・FFT・全バッファを確保して初期化。`setLatencySamples(0)`。
- 対応外のサンプルレート（44.1 / 48 / 96 kHz 以外）: $f_s \le 50$ kHz は $N = 2048, H = 256$、それより上は $N = 4096, H = 512$ で動かす。バンド表と行列は実際の $f_s$ で計算するので動作はするが、合格基準の対象外。
- 15 kHz がナイキストの 0.49 倍を超える低いレートは対象外。

### 8.3 `ClosedLoopBench`

**仮想ループ**（48 kHz・Mono）：

$$x[n] = s[n] + G \cdot (h * y)[n - D],\qquad y = \mathrm{Plugin}(x)$$

- $s[n]$: ピンクノイズ、−50 dBFS RMS（種固定）。
- $D$: 5 / 12 / 25 ms。
- $h$: 架空の会場 3 種（下表）。$h[n] = \delta[n] + \rho\, \nu[n]\, e^{-6.91 n / (RT_{60} f_s)}$（$n \ge 1$、$\nu$ は種固定の正規乱数）を 80 Hz〜12 kHz の帯域に絞り、周波数応答の最大値が 0 dB になるよう正規化する。

| 名前（架空） | $RT_{60}$ | $\rho$ | 乱数の種 |
|---|---|---|---|
| ROOM-A | 0.4 秒 | 0.05 | 1001 |
| ROOM-B | 0.9 秒 | 0.04 | 1002 |
| ROOM-C | 1.6 秒 | 0.03 | 1003 |

3 会場 × 3 遅延 = 9 条件すべてで実施する。

**測り方の定義**：
- 短時間レベル: 出力 $y$ の 20 ms 矩形窓 RMS（1 ms ごと）。
- 発散: $|x[n]| > 4.0$ になった時点、または最後の 1 秒の RMS が −20 dBFS 以上。
- $G_0$: `bypass = ON` で 6 秒走らせ、発散しない最大の $G$（0.1 dB 刻みの二分探索）。
- $G_{max}$: プラグイン有効で 15 秒走らせ、「発散せず、最後の 5 秒の RMS が $s$ の RMS + 6 dB 以下」を満たす最大の $G$（0.1 dB 刻み、上限 $G_0 + 20$ dB）。
- 収束時刻 $t_c$: 短時間レベルが −30 dBFS 未満の状態が 200 ms 続いた最初の時刻。
- 定常レベル $L_{ss}$: $[t_c,\ t_c + 10\,\mathrm{s}]$ の短時間レベルの中央値。
- ハンチング 1 回: $t_c$ 以降に短時間レベルが $L_{ss} + 6$ dB を下から上へ横切ること。
- モードの追跡: プラグイン**入力** $x$ の STFT（$N = 512$、ホップ 48、Hann）。あるビンのレベルが「その時刻のスペクトル中央値 + 15 dB」を超えた最初の時刻を $t_{emerge}$、その後の最大値の時刻を $t_{peak}$（最大値から 6 dB 以上下がったことを確認）とし、$T_{hop} = t_{peak} - t_{emerge}$。

| ID | 手順 | 【合格基準】 |
|---|---|---|
| CL-1 | $G_0$ と $G_{max}$ を測る | 9 条件すべてで $G_{max} - G_0 \ge 6.0$ dB |
| CL-2 | $G = G_0 + 6.0$ dB で固定し、$t_c + 10$ 秒まで走らせる | 9 条件すべてでハンチング 0 回 |
| CL-3 | CL-2 と同じ走行で、2 本目以降に現れた各モードの $T_{hop}$ を測る | すべて 50 ms 以下。1 本目は参考値として記録（目標 150 ms 以下） |
| CL-4（追加） | $G = G_0 + 6.0$ dB で 120 秒 | ハンチング 2 回以下、かつ各回の短時間レベルが $L_{ss} + 12$ dB を超えない |

### 13.2 分かったこと

1. **+6 dB を稼ぐと、同じくらい音量が下がる。** 発振限界 +6 dB で安定した条件では、40 バンド中およそ 20 本が下がり、EQ の平均の下げ幅は 5〜7 dB だった。「限界が 6 dB 上がる」ことと「6 dB 大きく出せる」ことは別で、後者はほとんど得られていない。帯域が 1/5 オクターブ幅と広いこと、試験用の会場が残響主体で山が多いことが原因。40 バンド固定という構成の限界に近い。
2. **声の保護と発振の検出が両立していない。** 遅延が支配的なループでは、発振の候補が等間隔に並ぶ（5 ms の遅延なら約 190 Hz おき）。これは声の倍音と同じ並び方なので、「等間隔なら声」と判定すると発振を見逃し、判定を緩めると声を切る。今の実装は「同じ調子で伸び続けている山は発振」という条件で分けているが、スピーチの立ち上がりで誤作動している（VT-1）。
3. **急に伸びる発振はスペクトルの裾が広がる。** 定常のサイン波を前提にした突出度の測り方だと見逃す。比較範囲を広げて対処した。

### 13.3 Phase 1 の設計（§5）から変えた点

| 項目 | §5 の記述 | 現在の実装 | 理由 |
|---|---|---|---|
| 解析の間隔（§2.1） | ホップ 128（96 kHz は 256） | ホップ 256（96 kHz は 512） | 処理の重さを抑えるため |
| ステレオの合成（§5.4） | 左右の振幅の重みつき合成 | 左右のパワーの大きい方 | 独自の式に置き換え。振幅だけを見るので逆相でも打ち消し合わない |

## 14. 設計案 A：動くノッチを足す（実装済み・合格基準には未達）

§13 の 2 つの問題（音量の落ち込み、声との区別）に対する設計案。**この章は案であり、承認後に §4・§5 へ組み込んで書き直す。**

### 14.1 考え方

- 発振は 1 本の細い周波数で起きる。それを 1/5 オクターブ幅の帯域で切るから、周りの音まで下がる。**発振には細いノッチ（幅 約 1/20 オクターブ）を、発振の周波数ちょうどに置く。**
- 40 バンドの EQ は残すが、役割を「ノッチが足りなくなったとき・同じ帯域に発振が密集したときの予備」に下げる。
- 声との区別には**周波数の安定度**を使う。発振は周波数が動かない。声の倍音は、まっすぐ伸ばした声でも数 Hz は揺れる。

### 14.2 構成

```
入力 ─► DC Blocker ─► 40 バンド EQ（予備）─► ノッチ ×12（直列）─► 異常ガード ─► リミッター ─► …
```

| 項目 | 値【設計値】 | 説明 |
|---|---|---|
| ノッチの本数 | 12 | 直列。使っていないノッチは 0 dB（素通し）で動かし続ける |
| ノッチの型 | §4.4 と同じ SVF のベル | 遅延 0 のまま。カット専用 |
| ノッチの Q | 30 | 幅 約 1/20 オクターブ |
| ノッチの最大の深さ | STRENGTH と FLOOR に従う（§13.3 の式） | 40 バンドと同じ決め方 |
| 周波数の決め方 | FFT の山の位置を、隣のビンとの位相の進み方から 1 Hz 程度の細かさで求める | ビン幅（約 23 Hz）より細かく合わせるため |
| 周波数の付け替え | そのノッチが 0 dB のときだけ行う | 動かすときのノイズを出さないため |

### 14.3 検出の流れ（§5.5〜§5.8 を置き換える）

1. 山を見つける（突出度。§13.3 の測り方）。
2. 山ごとに「周波数の安定度」を測る：直近 100 ms の周波数のばらつきが ±2 Hz 以内なら「安定」。
3. 「安定」かつ「落ち込んでいない」山を発振の候補にする。等間隔かどうかの判定（倍音列の判定）は、**安定度の条件を満たした山には使わない**（遅延が主体のループで発振を見逃す原因だったため）。
4. 候補が確認できたら（スコア。§5.6）、空いているノッチをその周波数に割り当てる。すでに近く（±1/40 オクターブ）にノッチがあれば、そのノッチを深くする。
5. 深さは「まだ収まり始めていない間だけ進める」（§13.3）。Hold・Release・再発時の延長は §5.8 のまま、ノッチ単位で持つ。
6. ノッチが 12 本とも埋まったら、いちばん浅いノッチを解放せず、その発振は 40 バンド側で切る（予備）。

### 14.0 実装した結果（2026-11-27）

この案は実装済み（ノッチ 12 本、周波数の安定度の判定）。結果は §13.1。**見込みと違った点**：

- **音量の落ち込みは減らなかった**（見込み 1〜2 dB → 実測 4.2〜8.2 dB）。発振限界 +6 dB では発振の候補が 20 本前後あり、ノッチ 12 本では足りずに 40 バンド側が働く。24 本に増やしても帯域側の働きはほとんど減らなかった（原因は未解明）。
- **周波数の安定度は声の保護に効いた**（VT-1 が 5.5 dB 低下 → 0.00 dB）。
- **声の保護を効かせると、発振の検出が遅れる**。「等間隔に並ぶ山は倍音とみなす」幅を 15 dB にすると声は守れるが発振が大きくなり、6 dB にすると発振はすぐ止まる（最大 −20 dBFS 以下、再発ほぼ 0）が声を切る。この 1 つの定数で両者が入れ替わる。
- 周波数は位相ではなく、山の両隣のレベルからの放物線補間で求めている（§14.2 からの変更。精度は未評価）。

### 14.0.1 追加の調査（2026-11-27。コードには残していない）

音量低下の原因を調べた結果：

- **発振限界 +6 dB では、開始から約 0.25 秒で 12 本のノッチがすべて埋まる。** その後に出てくる発振（さらに 10 本以上）は 40 バンド側が受け持つので、音量が下がる。試験用の会場は、+6 dB で不安定になる周波数が 20 本以上ある。
- ノッチが空いているのに帯域側も同じ発振を掴む場面があった（ノッチの受け持ち範囲が ±3 ビンで、スコアの裾が残る ±5 ビンより狭いため）。
- 次の 3 つを試したが、どれも音量低下・再発・収束時間を改善しなかったので取り込んでいない：受け持ち範囲を ±5 ビンに広げる／ノッチを 24 本に増やす／スコアがしきい値を超えた時点でノッチを確保する。24 本にしても帯域側の平均下げ幅は 3〜6 dB のままで、発振が一時的に 0 dBFS まで上がる条件はむしろ増えた。**原因は未解明。**

次に調べること：発振が 0 dBFS まで上がる場面（ROOM-B・ROOM-C）で、その周波数の検出が何に止められているかを 1 件ずつ追う。これまでに見つかった 3 件（倍音判定、突出度の測り方、解析範囲の下限）はいずれも検出側の見落としだった。

## 15. 実際の PA に近づけた試験用の経路（追加。記録のみ）

§8.3 の会場（ROOM-A〜C）は残響だけでできており、発振限界 +6 dB で不安定になる周波数が 20 本以上ある。実際の PA では直接音が主体で、発振は機材や部屋の山（共振）の数本に集まる。方式の良し悪しと会場の難しさを切り分けるため、経路をもう 1 組足した。**§8.3 の 9 条件と合格基準は変えていない（引き続き毎回測る）。**

### 15.1 経路の作り方（PA-1〜PA-3。すべて架空。乱数の種 2001〜2003）

| 要素 | 内容 |
|---|---|
| 直接音 | 大きさ 1 |
| 反射 | 8 本。遅れ 3〜40 ms、大きさ −6〜−16 dB、符号は交互 |
| 残響 | 20 ms 以降、$RT_{60}$ = 0.5 秒、係数 0.006 の弱い雑音 |
| 機材の山 | 200 Hz〜8 kHz のどこかに 3 つ。+6〜+10 dB、Q 6（振幅だけ掛ける） |
| 帯域 | 80 Hz〜12 kHz。周波数応答の最大を 0 dB にそろえる。長さ 0.35 秒 |

遅延 5 / 12 / 25 ms と組み合わせて 9 条件。測り方は §8.3 と同じ。

### 15.2 結果（発振限界 +6 dB、既定の設定）

| 項目 | 合格基準（§8.3・§14.5 と同じ） | PA-1〜3 の結果 | 参考：ROOM-A〜C |

| 安定 | 9 条件すべて | 9 / 9 | 9 / 9 |

| 収束後の音量低下 3 dB 以内 | 9 条件すべて | 6 / 9（2.3〜4.0 dB） | 0 / 9（4.2〜8.2 dB） |

**読み取れること**: 実際の PA に近い経路では、合格基準にかなり近い。残響だけの会場での未達の多くは、会場の難しさ（発振の候補が多すぎること）による。ただし PA に近い経路でも 3 項目は未達のままで、方式の改善は引き続き必要。

この経路が「実際の PA に近い」というのは一般的な性質からの設計で、**実測した会場の応答と照らし合わせてはいない**（未検証）。

### 15.3 フェーダーを徐々に上げた場合（追加。記録のみ）

§8.3 と §15.2 は、発振限界 +6 dB のゲインを**いきなり**かける。すると複数の発振が同時に立ち上がり、「2 本目以降は 50 ms 以内」の測定に、立ち上がり直後の混雑が入る。実際の現場ではフェーダーを徐々に上げるので、その使い方も測る。

手順：PA-1〜3 × 遅延 3 種。ゲインを「発振限界 −6 dB」から「発振限界 +6 dB」まで 5 秒かけて直線（dB）で上げ、その後 14 秒保つ。測り方と合格基準は §8.3・§14.5 と同じ。

| 項目 | 合格基準 | 結果 |
|---|---|---|
| 安定 | 9 条件すべて | 9 / 9 |
| 再発 0 回 | 9 条件すべて | 9 / 9 |
| 50 ms 以内に収束 | 9 条件すべて | 9 / 9（そもそも発振が −40 dBFS を超えたのは 1 条件だけで、最大 −39 dBFS） |
| 収束後の音量低下 3 dB 以内 | 9 条件すべて | 5 / 9（2.2〜4.1 dB。超過は 3.1・3.1・3.7・4.1 dB） |

**読み取れること**: PA に近い経路でフェーダーを徐々に上げる使い方なら、発振は聞こえる大きさになる前に抑えられている。残る未達は音量低下だけ。

#### 追記（文書バージョン 0.6.0）：深さを少し戻す修正で、この条件はすべて合格

収束後の状態を調べると、必要な深さ（+6 dB ぶん＋余裕）に対してノッチや帯域が −12〜−19 dB まで下がっていた。発振が収まり始めてから検出が止まるまでの遅れのぶん、深くなりすぎている。そこで**保持に移るとき、深さを 0.6 倍に戻す**ようにした（`settleBack = 0.6`。戻しすぎて再発したら、すぐ再開して少し深くなる）。

| 項目 | 修正前 | 修正後 |
|---|---|---|
| 安定 / 再発 0 回 / 50 ms 以内 | 9 / 9 | 9 / 9 |
| 音量低下 3 dB 以内 | 5 / 9（2.2〜4.1 dB） | **9 / 9（1.8〜2.6 dB）** |

雑音の種を 3 通り（7・99・2026）に変えても、安定 9 / 9、再発 0 回、音量低下は最大 2.7 dB だった。ただし種 7 で 1 条件だけ、収束に 279 ms かかった（発振の最大 −23 dBFS）。

この条件のテスト（CL-PA-R）は「記録のみ」をやめ、合否に含めるようにした。

試して採用しなかった案：深くする速さを遅くし、急に伸びる・大きい発振だけ速くする（音量低下は変わらず、いきなりかける条件で収束が悪化）。

いきなりかける条件（§15.2）の修正後：安定 9 / 9、再発 0 回 6 / 9、50 ms 以内 6 / 9、音量低下 3 dB 以内 7 / 9（1.7〜3.1 dB）。

### 15.4 周波数の求め方の精度（確認済み）

ノッチの周波数は、山の両隣のレベルからの放物線補間で求めている。既知の周波数のサイン波（187〜9876 Hz、−50 dBFS のピンクノイズを重ねる）で測ったところ、誤差は定常で最大 0.72 Hz、成長中（100・400 dB/秒）で最大 0.97 Hz だった。ノッチの幅（Q 30。562 Hz で約 19 Hz）に対して十分小さい。

あわせて、画面に出す「発振の周波数」（`peakHz`）がビンの中心（約 23 Hz 刻み）になっていたのを、細かく求めた値に直した。

### 15.5 120 秒の試験（CL-4）と、そこで見つけた見逃し（文書バージョン 0.8.0）

CL-4 を実装した。発振限界 +6 dB のまま 120 秒走らせ、保持（Hold）が切れて戻し始めた後の再発を数える。徐々に上げる走行では、上げ終わった時刻から数える。合格基準は §8.3 のまま（再発 2 回以下、定常レベルからの盛り上がり 12 dB 以内）。

**見つけた見逃し**: PA-2・遅延 25 ms で、70 秒付近に 1750 Hz の発振が −50 dBFS から −16 dBFS まで 1.6 秒かけて伸び、緊急の例外（−12 dBFS 付近）に当たるまで抑えられなかった。原因は、1751 Hz と 1783 Hz の 2 本が同時に伸びていたこと。解析では 1 つの山に見え、うなりで見かけの周波数が 1749〜1761 Hz を約 25 ms 周期で往復し、「周波数が 4 Hz 以上動いたら声」の判定に毎回当たってスコアが 0 に戻っていた。§5.6 の判定を 2 通りに分けて直した。

| 条件（PA に近い経路・徐々に上げる・120 秒） | 修正前 | 修正後 |
|---|---|---|
| PA-1 5 / 12 ms、PA-2 5 / 12 ms、PA-3 12 / 25 ms | 再発 0〜1 回、盛り上がり 4.6〜9.6 dB | 再発 0 回、4.8〜5.9 dB（合格） |
| PA-1 25 ms | 15 回、9.6 dB | 1 回、15.5 dB（未達。上げ終わった直後の 241 Hz の最初の発振） |
| PA-2 25 ms | 11 回、**35.8 dB** | 6 回、9.3 dB（未達。上げ終わった直後と、保持が切れた 23〜24 秒） |
| PA-3 5 ms | 4 回、6.8 dB | 7 回、7.5 dB（未達。すべて上げ終わった直後の 0.2 秒間） |

- 「再発」の回数は、短時間レベルが「定常 +6 dB」を下から上へ横切った回数。雑音（−50 dBFS）に近い小さな盛り上がりが境目で上下すると、1 回の出来事が数回に数えられる。数え方は変えていない。
- 残る未達のうち 2 条件は、保持が切れた後の再発ではなく、上げ終わった直後の最初の発振。もう 1 条件（PA-2・25 ms）は、同じ 1 秒の間に掴んだノッチと帯域の保持が同時に切れ、いっせいに戻し始めることで起きる小さな盛り上がり（定常 +9 dB、約 −42 dBFS）。
- 残響主体の会場（いきなりかける）は 0 / 9（再発 15〜109 回、盛り上がり 17〜50 dB）。
- 声のテスト（VT-1〜3）は修正後も音量低下 0.00 dB・誤作動なし。CL-PA-R は 9 / 9 のまま（音量低下 1.6〜2.6 dB）。いきなりかける PA 条件は、再発 0 回 7 / 9、50 ms 以内 6 / 9、音量低下 3 dB 以内 8 / 9。
- **未確認**: 修正後に雑音の種を変えた確認はしていない。実際の声（録音）での確認もしていない。「その場の揺れ 16 Hz まで許す」ぶん、ゆっくり音程が動く声への守りは修正前より弱い（合成のテスト 3 種では差が出なかった）。

#### 追記（文書バージョン 0.9.0）：保持の長さをずらす

| 試した案 | 120 秒（PA に近い経路・徐々に上げる） | 採否 |

## 16. Step 2 の区切り（2026-11-27、おまかせにより決定）

Step 2 は、合格基準に届かない項目を残したまま区切り、Step 3（画面とプラグインのビルド）へ進む。**基準は緩めていない。未達のテストは「記録のみ」として毎回結果を出し続ける。**

| 区分 | テスト | 状態 |
|---|---|---|
| 合否に含める（すべて成功） | ZL-1〜9、LV-1、VT-1〜3、CL-1、CL-PA-R | 合格 |
| 記録のみ（未達） | CL-2、CL-3、CL-5（残響主体の会場にいきなり +6 dB） | 未達 |
| 記録のみ（未達） | CL-PA（PA に近い経路にいきなり +6 dB） | 再発 0 回 7 / 9、50 ms 以内 6 / 9、音量低下 8 / 9 |
| 記録のみ（未達） | CL-4（120 秒） | PA に近い経路・徐々に上げる 7 / 9、残響主体 0 / 9 |

こう決めた理由：

1. 実際の使い方（PA に近い経路でフェーダーを徐々に上げる）では、10 秒の基準をすべて満たし、120 秒でも 9 条件中 7 条件を満たす。
2. 未達が残るのは「残響だけの経路」と「いきなり +6 dB」で、どちらも試験用に作った厳しい条件。これ以上は、実際の会場の測定データや実機での試聴なしに定数を動かしても、良くなったかどうか判断できない。
3. 実機で試すにはプラグインとして動く形が要る。Step 3 を先に進めたほうが、残りの調整の材料が早く手に入る。

Step 3 の後に戻って取り組むこと：いきなりかける条件、120 秒の残り 2 条件、実際の会場の応答と実際の声での確認、M4 実機での処理の重さ。
